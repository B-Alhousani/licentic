INFRASTRUCTURE
Count the hardware the software runs on.
Per core
A1
Counts: physical or virtual cores
License every core the software can run on. Most vendors set a floor per processor or per server, so small hosts still pay the minimum.

THE PAYMENT LAYER Any metric above can be sold on any of these terms.
Perpetual plus support Own the version forever, pay yearly for updates and help. Oracle Database, SAP ERP, SQL Server in volume licensing.
Subscription Right to use for a term, as in RISE with SAP. New VMware purchases are subscription only: 16 cores per CPU, 72 cores minimum per product since 10 Apr 2025 [1].
Enterprise agreement An organization wide commitment with true ups or a certification at the end. Microsoft Enterprise Agreement, Oracle ULA.
THE DESTINATION
Only once you understand how you are counted can you start saving.
Every model on this map is a lever. Count right, license right, pay for what you use.
